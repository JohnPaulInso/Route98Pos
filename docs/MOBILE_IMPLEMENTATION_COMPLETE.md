## 🎨 Design System

### Spacing Scale
```css
- Page padding: 16px (applied to children, not view)
- Card padding: 18-20px
- Button padding: 12-18px
- Grid gaps: 12-16px
- Modal padding: 20px
```

### Touch Targets
```css
- Standard button: 44px height
- Small button: 38px height
- Large button: 52px height
- Icon button: 44x44px square
- Chip: 36px height
- Input field: 44px height
```

### Typography Scale
```css
- Base: 14px (mobile html)
- Small text: 0.75-0.85rem
- Body text: 0.9-1rem
- Headings: 1.05-1.3rem
- Large numbers: 1.5-2.5rem
```

### Responsive Breakpoints
```css
- Mobile: < 768px (all fixes)
- Small mobile: < 375px (tighter)
- Landscape: < 500px height (optimized)
```

## 🛠️ Maintenance Guide

### Adding New Mobile Styles
1. Edit `css/mobile-fixes.css`
2. Add within `@media (max-width: 767px)`
3. Use `!important` to override base styles
4. Test on real device
5. Verify no horizontal scroll

### Common Issues

**Issue: New page has horizontal scroll**
```css
/* Add to mobile-fixes.css */
@media (max-width: 767px) {
  .new-page-container {
    padding: 0 16px !important;
    max-width: 100vw !important;
  }
}
```

**Issue: Button too small**
```css
@media (max-width: 767px) {
  .custom-btn {
    min-height: 44px !important;
    min-width: 44px !important;
  }
}
```

**Issue: Text breaking vertically**
```css
@media (max-width: 767px) {
  .text-element {
    word-wrap: break-word;
    overflow-wrap: break-word;
    white-space: normal;
  }
}
```
